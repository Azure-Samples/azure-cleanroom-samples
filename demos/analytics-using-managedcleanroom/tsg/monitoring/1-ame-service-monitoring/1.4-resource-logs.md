# 1.4 Resource Logs (AKS Diagnostic Settings)

## Overview

AKS control plane logs — not application logs, but the **Kubernetes platform itself**. These help debug cluster-level issues: why a pod wasn't scheduled, why an API call was rejected, why autoscaling didn't trigger.

## Current State

**Status: TBD** — Diagnostic Settings not yet enabled on AME AKS clusters.

## Log Categories

| Category | What It Contains | Volume | Recommended |
|----------|-----------------|--------|-------------|
| `kube-audit-admin` | API server mutations (create, update, delete — not GET/LIST) | Medium | ✅ Yes |
| `kube-audit` | Full audit including GET/LIST | **Very High** | ❌ Skip (too expensive) |
| `kube-apiserver` | API server logs | Medium | ✅ Yes |
| `kube-controller-manager` | Controller reconciliation events | Low | ✅ Yes |
| `kube-scheduler` | Pod scheduling decisions | Low | ✅ Yes |
| `guard` | AAD/RBAC authentication events | Low | ✅ Yes |
| `cluster-autoscaler` | Node scaling decisions | Low | ✅ Yes |

### Cost Optimization

- **Skip `kube-audit`** — very high volume, `kube-audit-admin` captures all mutations
- **Use resource-specific mode** — routes to dedicated tables (e.g., `AKSAudit`) instead of generic `AzureDiagnostics`
- **Configure `AKSAudit` as Basic logs tier** — cheaper, 8-day retention sufficient for audit data

## Example Queries

```kql
// Recent API server mutations (who changed what)
AKSAudit
| where TimeGenerated > ago(1h)
| where verb in ("create", "update", "patch", "delete")
| project TimeGenerated, verb, requestURI, user_username, responseStatus_code
| order by TimeGenerated desc

// Failed scheduling decisions
AKSControlPlane
| where Category == "kube-scheduler"
| where log_s contains "FailedScheduling"
| project TimeGenerated, log_s

// Autoscaler events
AKSControlPlane
| where Category == "cluster-autoscaler"
| project TimeGenerated, log_s
| order by TimeGenerated desc

// Guard (auth) failures
AKSControlPlane
| where Category == "guard"
| where log_s contains "Deny" or log_s contains "Forbidden"
| project TimeGenerated, log_s
```
