# 5.1 Business Metrics (Adoption & Usage)

## Overview

Business metrics for leadership reporting — adoption trends, usage patterns, regional distribution. Sourced from Geneva → Kusto pipeline and Cosmos DB.

## Current State

**Status: TBD** — No business dashboards exist. Data sources are available but not aggregated.

## Metrics

### Adoption Metrics

| Metric | Source | Frequency | Description |
|--------|--------|-----------|-------------|
| Active collaborations | Cosmos DB | Daily | Count by subscription, tenant, region |
| New collaborations created | RP Worker telemetry | Daily | Count, trend over time |
| Collaborations deleted | RP Worker telemetry | Daily | Count, trend over time |
| Net growth | Computed | Daily | New - Deleted |
| Unique tenants using ACCR | ARM Activity Log | Weekly | Distinct tenant count |
| Unique subscriptions | ARM Activity Log | Weekly | Distinct subscription count |
| Regional distribution | RP Worker telemetry | Weekly | Collaborations by Azure region |
| Workload types enabled | RP Worker telemetry | Weekly | Count by workloadType |

### Usage Metrics

| Metric | Source | Frequency | Description |
|--------|--------|-----------|-------------|
| Query execution count | Frontend Service telemetry | Daily | Total queries submitted |
| Query success rate | Frontend Service telemetry | Daily | COMPLETED / (COMPLETED + FAILED) |
| Data volume processed | Frontend Service telemetry | Daily | Total rows read/written |
| Average query duration | Frontend Service telemetry | Daily | P50/P95 of query execution time |
| Average collaboration lifetime | Cosmos DB + ARM | Weekly | Time from creation to deletion |
| Workload utilization | Frontend Service telemetry | Weekly | Queries per collaboration |

## Example Dashboard Queries

```kql
// Active collaborations by region (daily snapshot)
CleanRoomOperations
| where Timestamp > ago(24h)
| where TaskName == "HealthCheck"
| where Level == "Information"
| summarize ActiveCollabs=dcount(CollaborationName) by Region
| order by ActiveCollabs desc

// Weekly creation trend
CleanRoomOperations
| where Timestamp > ago(90d)
| where TaskName == "CreateCollaborationFinalize"
| where Level == "Information"
| summarize Created=count() by bin(Timestamp, 7d)
| render timechart

// Query volume and success rate (daily)
CleanRoomOperations
| where Timestamp > ago(30d)
| where Service == "Frontend"
| where TaskName == "QueryExecution"
| summarize 
    Total=count(),
    Succeeded=countif(Level == "Information"),
    Failed=countif(Level == "Error")
  by bin(Timestamp, 1d)
| extend SuccessRate = round(100.0 * Succeeded / Total, 1)
| render timechart

// Top tenants by collaboration count
CleanRoomOperations
| where Timestamp > ago(7d)
| where TaskName == "HealthCheck"
| summarize CollabCount=dcount(CollaborationName) by TenantId
| top 10 by CollabCount
```
